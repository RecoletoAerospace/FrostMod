# Frost Mod

Frost Mod is a project i've inherited from a guy who inherited it from other guys and so on, but they all stopped working on it so i asked for permission and decided to take over it myself. It's pretty simple, it adds several frost parts that you can attach to a SEP/FnB Starship part (each one has a specific frost matching the tank size) and it generates frost on the vehicle that goes down as you consume fuel. I tried to make it as realistic as possible, with accurate size, where does it start, where does it end... I intend to keep it up to date with the starship mods that release/update and with any new info released by SpaceX or by any means to make it even more precise, regarding the size of the fuel tanks. 

## IMPORTANT, before installing it, delete the old frost_mod file as I have renamed almost everything to make it cleaner and more organized.

***If there is any clipping or z fighting with the thermal paint, rotate the frost part with the Q and E keys to make it go away.***

### Right now, the supported vehicles are:


-SEP Block 0 ship

-SEP Block 1 ship

-SEP Block 2 ship

-SEP Block 1 booster

-FnB Block 2 ship

-FnB Block 3 ship

-FnB Block 0 booster

-FnB Block 1 booster

-FnB Block 3 booster (both the single piece booster and the multiple sections one)

In the future, Starhopper and HLS will also get frost, once i find the tank sizes and get some decent references of them.
The frosts don't have particles yet, i haven't been able to make them work, but i will keep on trying.
