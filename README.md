Frost Mod is a project i've inherited from a guy who inherited it from other guys and so on, but they all stopped working on it so i asked for permission and decided to take over it myself. It's pretty simple, it adds a frost part that you can attach to a SEP/FnB fuel tank and it generates frost on the vehicle that goes down as you consume fuel. I tried to make it as realistic as possible, with accurate size, where does it start, where does it end... I intend to keep it up to date with the starship mods that release/update and with any new info released by SpaceX or by any means to make it even more precise, regarding the size of the fuel tanks. Important, before installing it, delete the old frost_mod file as I have renamed almost everything to make it cleaner and more organized, and if there is any clipping or z fighting with the thermal paint, rotate the frost part with the Q and E parts to make it go away
